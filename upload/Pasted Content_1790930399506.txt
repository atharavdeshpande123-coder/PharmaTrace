1. CORE PROJECT OBJECTIVE
   ==================================================

Build a blockchain-based pharmaceutical drug authentication and supply-chain tracking platform.

The system should allow pharmaceutical manufacturers to register drug batches and generate unique QR codes.

The supply-chain participants should be able to update and track the movement of a drug batch.

A user/customer/pharmacist should be able to scan or manually enter a QR/batch code and verify whether the drug is authentic.

The system should show:

1. Drug identity
2. Drug name
3. Manufacturer
4. Batch number
5. Manufacturing date
6. Expiry date
7. Quantity
8. Current supply-chain status
9. Current owner/location
10. Complete supply-chain journey
11. Blockchain transaction history
12. Verification result
13. Timestamp
14. Tamper/invalid status where applicable

The main concept is:

Manufacturer → Distributor → Wholesaler → Pharmacy → Customer

Every important supply-chain event should create a blockchain-style immutable transaction record.

The verification process should compare the submitted QR/batch information against the registered blockchain record.

If the information is valid:
Display:

“AUTHENTIC DRUG”

If the drug does not exist:
Display:

“DRUG NOT FOUND / INVALID”

If the batch exists but has suspicious or inconsistent information:
Display:

“VERIFICATION FAILED / FLAGGED”

If the drug is expired:
Display:

“EXPIRED DRUG”

The UI must clearly distinguish these states.
