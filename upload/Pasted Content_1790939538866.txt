Build a complete, modern, futuristic, highly animated, fully responsive web application called:

# PharmaTrace

## Blockchain-Based Pharmaceutical Drug Authentication and Supply Chain Tracking System

TAGLINE:
"VERIFY. TRACE. TRUST."

==================================================

1. PROJECT OBJECTIVE
   ==================================================

Create a complete academic mini-project website that demonstrates how blockchain technology, QR-code-based identification, smart contracts, and a pharmaceutical supply-chain tracking system can be used together to authenticate pharmaceutical drug batches and trace their movement through the supply chain.

The website should feel like a combination of:

* Enterprise pharmaceutical technology
* Healthcare technology
* Web3
* Blockchain
* Cybersecurity
* Supply-chain intelligence
* Futuristic dashboard
* Digital verification platform

IMPORTANT:
This is an academic prototype/demo.

Do NOT claim that the website legally certifies medicines or guarantees that a physical medicine is medically safe.

The website should demonstrate:

* Pharmaceutical batch registration
* Unique batch/verification ID
* QR code generation
* QR code scanning
* Manual code entry
* Blockchain-style verification
* Smart-contract validation
* Supply-chain tracking
* Manufacturer information
* Manufacturing date
* Expiry date
* Batch information
* Blockchain transaction history
* Verification history
* Immutable-style audit trail
* Dashboard analytics
* Role-based workflows
* Interactive blockchain visualization

The architecture must be designed so that a real Hyperledger Fabric network can be connected later.

If a real blockchain network cannot run in the generated environment, implement a clearly separated blockchain simulation/development adapter.

NEVER falsely display "Blockchain Verified" when the backend has not actually performed the corresponding operation.
